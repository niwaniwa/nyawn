# Product

updated: 2026-03-28

---

## プロダクト名

`nyawn`（開発コードネーム。正式名称は別途決定）

一行説明: VRChatユーザーがオフラインイベントで使えるプロフィールカードを簡単に作成できるWebサイト

---

## コアバリュー

- **手軽さ**: 認証不要。サイトを開いて即座にカードを作り始められる
- **シンプルさ**: 開発者が用意したかわいいテンプレートを選ぶだけ。デザインスキル不要
- **実用性**: PNG画像としてダウンロードでき、オフラインイベント（meetup・即売会）で実際に使える

---

## ターゲット層（ペルソナ）

- **誰:** VRChat / ソーシャルVRコミュニティのユーザー（10代後半〜30代）
- **課題:** オフラインイベントで自分のVRアバターやSNS情報をまとめた名刺的カードが欲しいが、デザインツールを使うのは面倒
- **利用シーン:** オフライン即売会・集会の前に、スマホまたはPCでプロフィールカードを作成し、印刷・画面表示で共有する

---

## MVP定義

### スコープ内

- テンプレート選択（開発者提供の3〜5種類）
- カード編集（表示名 / アバター画像URL / ひとこと紹介文 / VRChat ID / SNSリンク2〜3個）
- リアルタイムプレビュー
- PNG画像としてダウンロード
- localStorageによるデータ自動保存（ブラウザを閉じても復元）
- レスポンシブ対応（モバイル / PC）

### スコープ外

- ユーザー認証 / アカウント機能
- カスタムテンプレート作成
- URL共有（カードのパーマリンク生成）
- QRコード生成（Phase 2候補）
- 複数カード管理（Phase 2候補）
- 多言語対応
- アバター画像のアップロード / ホスティング（MVPではURL指定のみ）
- 印刷最適化レイアウト

---

## ブランド・世界観

- **ブランドカラー:** パステル系をベースとした柔らかい配色（ピンク、ラベンダー、ミントなどのアクセント）
- **トーン:** やわらかい・親しみやすい・ポップ。VRChat文化に寄り添った雰囲気
- **世界観:** 「簡単に、モダンに、かわいく」— 丸みのあるUI、やわらかいシャドウ、パステルカラーのアクセント

---

## 競合との差別化

| 競合 | 差別化ポイント |
| --- | --- |
| Canva / 一般デザインツール | VRChat特化フィールド（VRC IDなど）を標準装備。認証不要で即利用可 |
| VRChat公式プロフィール | オフライン利用向け。画像DL可能。テンプレートによるカスタマイズ性 |
| 自作名刺（Illustrator等） | デザインスキル不要。テンプレートを選んで情報を入れるだけ |
