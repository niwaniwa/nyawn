# Primitive トークン

生の値に名前をつけた基本トークン。プロジェクトに応じて定義する。

## 色

| トークン名 | 値 | 用途 |
| --- | --- | --- |
| `color-blue-500` | `#3B82F6` | 青系の基準色 |
| `color-gray-100` | `#F3F4F6` | 薄いグレー |
| `color-gray-200` | `#E5E7EB` | ボーダー用グレー |
| `color-gray-400` | `#9CA3AF` | プレースホルダー用グレー |
| `color-gray-600` | `#4B5563` | サブテキスト用グレー |
| `color-gray-900` | `#111827` | 濃いグレー |
| `color-white` | `#FFFFFF` | 白 |
| `color-red-500` | `#EF4444` | 赤系の基準色 |
| `color-green-500` | `#22C55E` | 緑系の基準色 |
| `color-pink-300` | `#F9A8D4` | パステルピンク |
| `color-pink-400` | `#F472B6` | ピンク |
| `color-lavender-300` | `#C4B5FD` | パステルラベンダー |
| `color-lavender-400` | `#A78BFA` | ラベンダー |
| `color-mint-300` | `#6EE7B7` | パステルミント |
| `color-mint-400` | `#34D399` | ミント |
