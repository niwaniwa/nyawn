# Component トークン

Semantic トークンを特定のUIコンポーネントに紐づけたもの。

## ボタン

| トークン名 | 参照先 | 用途 |
| --- | --- | --- |
| `button-bg-primary` | `color-primary` | プライマリボタンの背景 |
| `button-text-primary` | `color-background` | プライマリボタンのテキスト |
| `button-bg-secondary` | `color-accent-light` | セカンダリボタンの背景 |
| `button-text-secondary` | `color-text` | セカンダリボタンのテキスト |
| `button-padding-x` | `spacing-md` | ボタンの左右パディング |
| `button-padding-y` | `spacing-sm` | ボタンの上下パディング |
| `button-radius` | `radius-lg` | ボタンの角丸 |

## カード（汎用）

| トークン名 | 参照先 | 用途 |
| --- | --- | --- |
| `card-bg` | `color-surface` | カード背景 |
| `card-padding` | `spacing-md` | カード内余白 |
| `card-radius` | `radius-xl` | カード角丸 |
| `card-shadow` | `shadow-card` | カードの影 |

## プロフィールカード

| トークン名 | 参照先 | 用途 |
| --- | --- | --- |
| `profile-card-width` | `320px` | カードの幅（固定） |
| `profile-card-padding` | `spacing-lg` | カード内余白 |
| `profile-card-radius` | `radius-2xl` | カード角丸 |
| `profile-card-shadow` | `shadow-elevated` | カードの影 |
| `profile-avatar-size` | `80px` | アバター画像サイズ |
| `profile-avatar-radius` | `radius-full` | アバター角丸（円形） |
| `profile-name-font` | `font-display` | 表示名のフォントサイズ |
| `profile-name-weight` | `font-weight-bold` | 表示名のフォントウェイト |
| `profile-bio-font` | `font-caption` | 紹介文のフォントサイズ |
| `profile-social-icon-size` | `20px` | SNSアイコンのサイズ |
| `profile-social-gap` | `spacing-sm` | SNSアイコン間の余白 |

## テンプレートギャラリー

| トークン名 | 参照先 | 用途 |
| --- | --- | --- |
| `gallery-card-width` | `240px` | ギャラリー内のカードサムネイル幅 |
| `gallery-card-radius` | `radius-lg` | サムネイルの角丸 |
| `gallery-gap` | `spacing-md` | カード間の余白 |

## インプット

| トークン名 | 参照先 | 用途 |
| --- | --- | --- |
| `input-bg` | `color-background` | 入力欄の背景 |
| `input-text` | `color-text` | 入力テキスト色 |
| `input-placeholder` | `color-text-placeholder` | プレースホルダー色 |
| `input-padding` | `spacing-sm` | 入力欄の内余白 |
| `input-radius` | `radius-lg` | 入力欄の角丸 |
| `input-border` | `color-border` | 入力欄のボーダー色 |
| `input-border-focus` | `color-primary` | フォーカス時のボーダー色 |
| `input-border-error` | `color-error` | エラー時のボーダー色 |
